Privacy policy

This policy covers the Google OAuth app private-automation and its tools todo-sync and gmail-headers. Only the app's owner uses them, with the owner's own Google account.

Data accessed

  • Google Tasks, read-only (tasks.readonly).
  • Gmail, read-only (gmail.readonly). The tool reads message headers.

Use and storage

The tools run on the owner's own computers and show the data there, as a local to-do list and as header search results. The OAuth refresh token is stored in a local file that only the owner can read. No data is sent to any server other than Google's APIs. Nothing is shared, sold, used for advertising or used to train AI models.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at Google Account permissions. Deleting the local token file removes the stored access as well.
